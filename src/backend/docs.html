☁️ Cloud-Native Architecture & Security Cloud Engine

Krusch-Nexus runs 100% cloud-native via OpenRouter Cloud AI (tagging: qwen/qwen-2.5-coder-32b-instruct, embeddings: baai/bge-large-en-v1.5 1024d), paired with Polygres Cloud pgvector storage.

🔒 TLS 1.3 / SSL Encrypted Storage (sslmode=require)
🛡️ Zero Data Retention Cloud AI (OpenRouter API)
🔑 Enterprise Document ACLs (RoleAclPostprocessor)
⚡ Real-Time Webhook & Google Workspace Sync

🛡️ OpenRouter Privacy Policy & TOS Audit Summary

  • ✓ Zero Data Retention Guarantee: OpenRouter's API Terms of Service strictly prohibit storing, logging, or retaining input prompts and completions.
  • ✓ No Model Training on Data: OpenRouter API contractually guarantees customer knowledge base text is NEVER used to train, fine-tune, or improve third-party AI models.
  • ✓ Client-Side Payload Encryption: Sensitive document payloads stored in database columns utilize zero-knowledge AES-256-GCM encryption (crypto_utils.py).
  • ✓ 100% Serverless Cloud-Native Architecture: Operates 100% in the cloud via Cloudflare Workers Edge, OpenRouter Cloud AI, and Polygres Cloud pgvector with zero dependency on local hardware or local servers.

🧠 Dual-MCP Architecture & krusch-context-mcp Integration Open Source Engine

Krusch-Nexus is powered by krusch-context-mcp—an open-source AI context & episodic memory engine. Together, they form a unified two-tier memory & institutional knowledge matrix:

📚 Krusch-Nexus (Shared Institutional Knowledge)

Manages organization-wide shared knowledge across all employees: SOP documents, financial reports, email sync, GraphRAG entity connections, SOP checklists, and SME expert routing.

⚡ krusch-context-mcp (Open-Source Episodic Engine)

The open-source engine powering per-employee agent episodic memory & session lifecycle: capturing key decisions, runtime bug solutions, operational lessons, and active priorities across agent turns.

⭐ View krusch-context-mcp on GitHub

🔄 Overarching PostgreSQL Sync & Superseding Knowledge

Centralizing institutional knowledge in an overarching Polygres Cloud PostgreSQL database guarantees that knowledge is always up to date across all employees. Updates instantly supersede outdated instructions across every employee's AI assistant in real time.

🛡️ Multi-Role Security ACLs & Isolation

Enforces Zero-Trust tenant and workspace isolation via RoleAclPostprocessor: non-management users automatically filter out sensitive confidential assets while maintaining seamless institutional RAG access.

💾 Persistent Episodic Memory Workflow Lifecycle AI Agent Protocol

AI Agents operating across employee workspaces follow a three-phase persistent memory workflow protocol powered by krusch-context-mcp:

1. Recall Phase

Agents execute krusch_context_search_memory & krusch_context_list_memories at session startup to load past decisions, bugs, and activity logs.

2. Capture Phase

Agents write structured memories via krusch_context_write_state under categories: bugs, decisions, lessons, and priorities.

3. Consolidation Phase

Memories are indexed into 1024d bge-large vector space and synchronized into local/cloud PostgreSQL tables for instant cross-session recall.

📄 Agent-Native MCP Document Ingestion Workflow IDE & Claude Code Native

In addition to visual web portal drag-and-drop and 1-click Google Workspace sync, developers and AI agents working inside Claude Code, Claude Desktop, Cursor, or Antigravity IDE can ingest files directly into Krusch-Nexus using the nexus_ingest_business_document MCP tool.

Example: Agent Invoking File Ingestion via MCP Tool

// Invoke from Claude Code, Cursor, or Stdio/SSE MCP Agent
use_mcp_tool({
  server_name: "krusch-nexus",
  tool_name: "nexus_ingest_business_document",
  arguments: {
    filename: "architecture_standard.md",
    content: "# Architecture Standard\n\nAll services must use TLS 1.3 encryption...",
    workspace_name: "repo:krusch-nexus",
    category: "SOP"
  }
});

Upon invocation, Krusch-Nexus parses the document, extracts GraphRAG entity connections, generates 1024d bge-large dense vector embeddings, and performs automated OpenRouter Qwen 32B security tagging—making the newly ingested document instantly queryable across the entire organization.

🔌 Krusch-Nexus Business MCP Tool Suite

The Model Context Protocol (MCP) server exposes enterprise tools for AI agents (Claude Desktop, Cursor, Antigravity, OpenClaw, Mobile Clients):

nexus_query_business_knowledge

Hybrid 1024d vector retrieval + GraphRAG relational entity linking across SOPs, emails, memos, and financial reports.

nexus_classify_document

Sets document security classification tiers ('public', 'internal', 'confidential', 'management_only') and role permissions.

nexus_flag_document_for_review

Flags sensitive or suspicious document assets for management review and security audit.

nexus_get_email_draft_context

Extracts company policy guidelines & client interaction context to draft professional, policy-compliant email replies.

nexus_ingest_business_document

Real-time document, SOP, or memo ingestion into workspace knowledge vector stores directly via MCP call from IDE or agent.

nexus_get_sop_checklist

Extracts structured, phase-by-phase operational action items and checklists from company SOP documents.

nexus_find_expert

Locates internal team Subject-Matter Experts (SMEs), role owners, or document authors for any topic.

nexus_sync_google_workspace

1-click synchronization of Gmail threads, Google Drive folders, Docs, Sheets, and Slides into workspace catalog.

🖥️ Claude Desktop Setup (Dual-MCP Configuration)

Add Krusch-Nexus and Krusch-Context-MCP to your claude_desktop_config.json configuration file:

{
  "mcpServers": {
    "krusch-nexus": {
      "command": "/bin/bash",
      "args": ["/home/krusch/homelab/projects/krusch-nexus/scripts/run_mcp.sh"],
      "env": {
        "NEXUS_API_KEY": "YOUR_NEXUS_API_KEY_HERE",
        "TAGGING_PROVIDER": "openrouter",
        "EMBEDDING_PROVIDER": "openrouter"
      }
    },
    "krusch-context": {
      "command": "python3",
      "args": ["-m", "krusch_context_mcp.server"],
      "cwd": "/home/krusch/homelab/projects/krusch-context-mcp"
    }
  }
}
